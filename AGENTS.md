# Rules for "lnkcnt" project

## About project

1. This project is a url shortener.
2. but it includes a url click counter feature.
3. This project uses Next.js.

## Code writing rules

1. Use TypeScript. DO NOT USE PLAIN JAVASCRIPT!
2. If possible, use shadcn or TailwindCSS.
3. This project is intended to host on podman.
4. Write JSDoc on functions, and variables.
5. DO NOT USE PLAIN SQL. instead, use Prisma ORM.

## File operation rules

1. **YOU SHOULDN'T DELETE A FILE WITHOUT USER'S EXPLICIT PERMISSION!**

## Shell operation rules

1. `shadcn-ui` is deprecated. use `shadcn` instead.

## Git operation rules

1. **YOU SHOULDN'T USE GIT'S FORCE PUSH AND HARD RESET FEATURE!**
